( 02 ) The research

Flagging recruitment fraud before you apply.

Thousands of job seekers fall prey to postings that never existed. My final-year research examined whether an applied ML architecture could flag recruitment fraud before an applicant submits credentials — and provide verifiable reasoning.

  1. 01

    Semantic encoding

    DistilBERT contextual embeddings

    Extracts dense high-dimensional semantic representations from unstructured job descriptions, capturing nuanced deceptive linguistic patterns.

  2. 02

    Anomaly isolation

    Isolation Forest safety layer

    Unsupervised safety boundary that isolates structural anomalies unseen in training distributions, detecting zero-day scam variants.

  3. 03

    Classification

    Stacking ensemble classifier

    Meta-classifier combining semantic and tabular features to overcome the severe 95:5 authentic-to-fraudulent class imbalance.

01 / 03 · ICISD’26

Scam Detection

A machine taught to recognise a lie.

  • The problem

    Online job seekers fall victim to fraudulent recruitment postings that harvest identity credentials. The EMSCAD benchmark has an extreme 95:5 class imbalance — a naive classifier predicting “authentic” blindly scores 95% accuracy while remaining entirely useless.

  • The approach

    Architected a hybrid neuro-symbolic pipeline combining DistilBERT contextual embeddings for deep semantic representation, an Isolation Forest safety boundary to detect out-of-distribution zero-day scams, and a Stacking Ensemble classifier.

  • The result

    Validated at 99% accuracy, 99.00 F1-score and 99.99% ROC-AUC. Published at ICISD’26 and deployed as a live cloud inspection dashboard with instant explainability reasoning.

02 / 03 · Security

Digital Diary

Private by construction, not by promise.

  • The problem

    Modern single-page web applications routinely store JWT authentication tokens in localStorage or client memory, leaving confidential user journals vulnerable to client-side XSS token exfiltration.

  • The approach

    Engineered a zero-framework platform using Python FastAPI, Jinja2 and vanilla JavaScript over SQLAlchemy. Authentication relies on cryptographically signed JWT access & refresh tokens stored strictly in HttpOnly, SameSite cookies with zero script exposure.

  • The result

    Complete mitigation of XSS token hijacking. Features granular emotional telemetry, mood analytics, archival pinning, and time-decayed sharing tokens over an automated OpenAPI backend.
