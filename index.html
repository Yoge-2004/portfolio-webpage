Chapter 03 // Peer-Reviewed Research

Teaching a machine to recognise a lie.

Thousands of job seekers fall prey to postings that never existed. My final-year research examined whether an applied ML architecture could flag recruitment fraud before an applicant submits credentials — and provide verifiable reasoning.

STEP 01 // SEMANTIC ENCODING

DistilBERT Contextual Embeddings

Extracts dense high-dimensional semantic representations from unstructured job descriptions, capturing nuanced deceptive linguistic patterns.

STEP 02 // ANOMALY ISOLATION

Isolation Forest Safety Layer

Unsupervised safety boundary that isolates structural anomalies unseen in training distributions, detecting zero-day scam variants.

STEP 03 // CLASSIFICATION

Stacking Ensemble Classifier

Meta-classifier combining semantic and tabular features to overcome the severe 95:5 authentic-to-fraudulent class imbalance.

SPATIAL CLUSTER // Z: -42.0m HYBRID NEURO-SYMBOLIC
DISTILBERT EMBEDDINGS ISOLATION FOREST ORBITALS
Published ICISD'26 Peer Reviewed Oral Presentation Paper ICISD26-408

Fake Job Posting and Online Recruitment Scam Detection Utilizing Machine Learning and Advanced Natural Language Processing Techniques

International Conference on Intelligent Systems and Digital Transformation (ICISD'26) SRM Institute of Science and Technology, Vadapalani Campus, Chennai · 6–7 April 2026

The architecture is hybrid neuro-symbolic. DistilBERT generates contextual semantic embeddings of job postings, an Isolation Forest isolates high-dimensional anomalies unseen in the training distribution, and a Stacking Ensemble makes the final classification. This unsupervised safety layer enables detection of zero-day scams that mimic legitimate recruitment formats.

A critical challenge was extreme class imbalance: the EMSCAD dataset exhibits an authentic-to-fraudulent ratio of 95:5. A naive classifier predicting "genuine" universally achieves 95% accuracy while remaining completely useless. Addressing this imbalance honestly is why our evaluation emphasizes F1-Score and ROC-AUC over superficial metrics.

PHASE 01 // THE CRISIS

The Problem: Online job seekers fall victim to fraudulent recruitment postings that harvest identity credentials. The EMSCAD benchmark has an extreme 95:5 class imbalance — a naive classifier predicting "authentic" blindly scores 95% accuracy while remaining entirely useless.

PHASE 02 // ARCHITECTURE

ZERO-FRAMEWORK SECURITY PROJECT // 02
OPEN SOURCE REPO

Private Digital Diary Platform

⚡ github.com/Yoge-2004/digital-diary-application

PHASE 01 // THE CRISIS

The Problem: Modern single-page web applications routinely store JWT authentication tokens in localStorage or client memory, leaving confidential user journals vulnerable to client-side XSS token exfiltration.

PHASE 02 // ARCHITECTURE

The Engineering Approach: Engineered a zero-framework platform using Python FastAPI, Jinja2, and vanilla JavaScript over SQLAlchemy. Authentication relies on cryptographically signed JWT access & refresh tokens stored strictly in HttpOnly, SameSite cookies with zero script exposure.

PHASE 03 // OUTCOME

The Result: Complete mitigation of XSS token hijacking. Features granular emotional telemetry, mood analytics, archival pinning, and time-decayed sharing tokens over an automated OpenAPI backend.
