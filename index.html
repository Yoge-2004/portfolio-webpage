Research

Teaching a machine to recognise a lie.

Thousands of people apply to job postings that were never real. My final-year research asked whether a model could flag the fraud before the application goes out — and explain enough of its reasoning to be worth trusting.

PublishedPeer reviewedOral presentationICISD26-408

Fake Job Posting and Online Recruitment Scam Detection Utilizing Machine Learning and Advanced Natural Language Processing Techniques

International Conference on Intelligent Systems and Digital Transformation (ICISD'26) SRM Institute of Science and Technology, Vadapalani Campus, Chennai · 6–7 April 2026

The system is hybrid neuro-symbolic. DistilBERT supplies contextual embeddings of the posting text, an Isolation Forest catches anomalies the supervised model has never seen, and a stacking ensemble of classifiers makes the final call. That unsupervised layer is what lets it flag zero-day scams instead of only the patterns it was trained on.

The hard part is class imbalance. In the EMSCAD dataset genuine and fraudulent postings run at roughly 95:5, so a model that answers "genuine" every single time already scores 95%. Handling that honestly is most of the work — which is why F1 and ROC-AUC carry the real signal here, not raw accuracy.

Exhibit 02

Digital Diary

github.com/Yoge-2004/digital-diary-application

A private-by-default journal, built deliberately without a front-end framework — FastAPI, Jinja2 and plain JavaScript over SQLAlchemy. Auth uses JWT access and refresh tokens held in httponly cookies rather than local storage.

Entries carry a mood, tags and an optional location, and each one can be favourited, pinned, archived or bookmarked independently. Sharing is per entry: grant one named user access, or mint a public link, either with an expiry. The dashboard tracks totals, mood distribution and current and longest writing streaks, and every page has a matching JSON API.
